## Additional Styling Notes

1. **Typography**: Use Inter or a similar clean sans-serif font. Headlines should be bold (700), body text regular (400).

2. **Spacing**: Generous padding between sections (80-120px). Cards should have comfortable internal padding (24-32px).

3. **Buttons**: 
   - Primary buttons: Teal (#10b981) background, white text, rounded corners (8px), subtle hover darkening
   - Secondary/outline buttons: White background, teal border and text, same rounded corners

4. **Cards**: White background, subtle shadow (0 4px 6px rgba(0,0,0,0.1)), rounded corners (12px), hover effect that lifts the card slightly

5. **The "Most Popular" pricing card**: Should stand out with a teal border (2px), slightly larger shadow, and the badge at the top

6. **Strikethrough prices**: Use CSS text-decoration: line-through and gray color to clearly show the discount

7. **Mobile responsiveness**: 
   - Navigation collapses to hamburger menu
   - Pricing cards stack vertically
   - Feature grid becomes single column
   - All text remains readable

8. **Smooth scrolling**: Add scroll-behavior: smooth to html element

9. **FAQ accordion**: Use JavaScript to toggle visibility with smooth height animation
